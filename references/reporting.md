# 报告表达

先判断读者需要知道事实、做选择、跟进工作还是学习方法。下面是可裁剪结构，不要求每份材料都有全部章节。

## 选择结构

**情况分析与决策建议**：当前判断与建议 → 事实及来源 → 主要差距和原因 → 可选路径及取舍 → 建议行动、依赖和失效条件。

**工作进展**：目标及当前状态 → 已完成工作和实际效果 → 尚未完成的问题 → 下一步动作及必要支持。进度写明截止时间，不把“已安排”写成“已解决”。

**操作流程**：适用对象与前提 → 输入与准备 → 具体动作及交接 → 异常处理 → 验收与接续。让首次执行的人能按文档做；只在容易误操作的环节规定精确动作。

**复盘与方法提炼**：原目标与当时条件 → 实际行动及结果 → 哪些判断得到支持、哪些被推翻 → 机制解释和其他可能原因 → 适用边界 → 下一次改变什么。避免事后把当时未知的信息写成早有预见。

## 段落的连接

每段先说一个要点，再给证据与解释。关键连接使用明确语义：

- 事实到判断：“记录显示……；据此可以确认……，但尚不能判断……。”
- 问题到动作：“目前缺少……，会阻止……；下一步先完成……，再开展……。”
- 方案到边界：“该建议依赖……；若……不成立，需要重新评估……。”
- 结果到状态：“已生成……并通过……检查；……仍待确认。”

这是逻辑示例，不是固定话术。表达可自然变化，但不能省略关键条件。使用“因此”前确认前文确实支持后文，不能用连接词制造不存在的因果关系。

## 示例：口径不一致时怎样写

以下为虚构练习数据，不能作为真实任务依据。

输入：财务记录显示本期到账80万元；合同清单列签约金额120万元；执行记录列待验收项目3项。

空泛表述：“项目全面完成，资金落实有力。”

可用表述：“现有财务记录显示，本期到账80万元，合同清单的签约金额为120万元，两项指标分别反映到账和签约状态，不能据此判断项目全面完成。执行记录中还有3项待验收项目。下一步应核对合同对应的应收节点，并按原验收要求检查这3项项目；核对完成前，不将其列为已完成。”

若要计算到账率，必须先确认80万元和120万元对应同一批合同、同一统计时段及相同金额口径。未确认时不输出66.7%的到账率。

## 删除空话但保留实质

- “持续推进”：补具体动作、截至何时、进展凭据；没有动作记录就保留为计划。
- “风险可控”：补风险类型、评估条件、应对路径及剩余风险；无法支持则改为尚待评估。
- “成效显著”：给基线、当前结果、比较条件；不能仅凭工作数量推断效果。
- “加强协同”：写清上一环交付什么、下一环谁接收、何时反馈异常。

正文保持紧凑，附录承载明细、公式和索引；不要把原始工具日志全贴进报告。需要用户做决定时，说明具体选择及影响，不重新询问已确认的偏好。
